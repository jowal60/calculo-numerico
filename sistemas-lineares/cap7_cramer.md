# Sistemas Algébricos
Desejamos resolver sistemas do tipo

$\qquad Ax = b$, onde

- $A$ é uma matriz de coeficientes de ordem $n$,

- $x$ é um vetor das desconhecidas de ordem  $n$, e
  
- $b$ é um vetor de dados de ordem $n$.
